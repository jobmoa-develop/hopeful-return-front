# 강의 일정(/calendar) 전체/내 일정 뷰 토글

`CourseCalendarPage`에 **뷰 토글**을 추가해, 전체열람 역할(관리자 등)도 일반 사용자처럼 본인 배정 회차·가용일을
먼저 보고 관리할 수 있게 한다. 관리자도 인력으로 배정될 수 있기 때문. **권한/메뉴 변경 없는 순수 뷰 전환.**

## 동작

- **토글:** 헤더 우측 `내 일정 | 전체 보기`. `UNRESTRICTED_ROLES`(ADMIN·HEAD_OFFICE·REGIONAL_MANAGER·
  PROJECT_MANAGER) 보유 사용자에게만 노출. **기본값 = 내 일정**.
- **내 일정(mine):** 본인이 배정(course_staff)된 회차만 표시 + 배정 날짜/세션 배지 + 본인 가용일(가능/불가) 관리.
  진행자·행정·PL·강사는 회차 전체 기간이 아닌 실제 배정 날짜만 노출(상담사는 회차 전체).
- **전체 보기(all):** 전 강좌 표시(개인 배정 맵 계산·per-course 호출 skip).
- **제한 역할 전용 사용자**(강사 등, 전체열람 역할 없음): 토글 없이 항상 내 일정(기존 동작 유지).

## 내 일정 표시 규칙 (후속 수정)

- **라벨:** 내 일정 뷰에선 관리자도 **필드형식**(`지역 · 지역회차 · N일차`). 관리자 전용 "N기 강좌명"은
  전체 보기에서만(`useAdminLabel = !showOnlyMine && isAdmin`).
- **지역색:** 지역별 **고유색**(전체 강좌 지역명 정렬 후 HSL 색상환 균등 분배) — 겹치지 않음.
- **우측 '강의 목록' 패널:** 날짜 **클릭 후에만** 표시(미선택 시 캘린더 전체 폭).
- **세션 배지(내 배정 시간대):** 사용자 계정 **강사(LECTURER) 역할 기준**.
  - 강사만: 셀에 세션 배지만. / 강사+다른 역할: 역할(강사)+세션. / 강사 없음: 셀엔 역할만, 세션은 우측 리스트에서.
  - 우측 패널 리스트는 전원 세션 표시(비강사가 확인하는 곳).

## 구현 메모

- 파생 플래그 `showOnlyMine = isRestricted || (canViewAll && viewMode === 'mine')`가 강좌 필터·개인 배정
  계산·일자 필터·헤더 라벨을 구동. 관리자 `isAdmin` early-return을 `!showOnlyMine`으로 완화해 mine 뷰에서
  관리자도 개인 배정 데이터를 계산한다.
- 이벤트 라벨/배지/범례의 `isAdmin` 표시 분기는 유지(최소 변경). 본인 가용일 등록 패널은 두 뷰 모두 동작.
- BE 변경 없음.
